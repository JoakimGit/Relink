# ReLink

A single-user link shortening and management tool. Create shortened URLs with optional constraints (password, expiration, visit caps), organize them with Groups, and track Visit analytics.

## Language

### Core

**Link**:
A shortened URL managed by the app. Each Link has a unique Short Code, a Long URL it redirects to, and optional constraints.
_Avoid_: ShortenedLink, shortened link, short link

**Short Code**:
The unique short identifier for a Link (e.g., `abc123`). Serves as the database primary key. Auto-generated by default.
_Avoid_: Id, slug, shortcode

**Preferred Short Code**:
A user-supplied Short Code instead of a randomly generated one. Must be unique; the request fails if it collides with an existing Short Code.
_Avoid_: Custom short code, preferred shortcode

**Long URL**:
The original, full-length URL that a Link redirects to.
_Avoid_: Original URL, destination URL, target URL

**Title**:
A short, human-readable name for a Link, required at creation. Displayed prominently on link cards and in search results. Distinct from Notes (a longer annotation) and from the scraped title in Link Metadata.
_Avoid_: Name, label

### Visits & Analytics

**Visit**:
A single instance of someone following a Link. Each Visit is recorded as a row in analytics with timestamp, IP, referrer, and user agent.
_Avoid_: Click, usage, hit, redirect

**Visit Count**:
The total number of Visits a Link has received. Resetting the Visit Count zeroes the count and erases the Link's analytics history.
_Avoid_: Click count, usage count, CurrentUsages

**Max Visits**:
An optional hard cap on Visits. A Link becomes inactive once Visit Count reaches this number.
_Avoid_: Max usages, click limit

### Constraints

**Password Lock**:
An optional password that must be entered before a Link can be visited. Stored as a salted hash.
_Avoid_: Password gate, password protection

**Start Date**:
A Link is only visitable on or after this date. Null means no start restriction.

**Expiration Date**:
A Link is no longer visitable after this date. Null means no expiration.

**Lock**:
A manual flag that makes a Link inactive, overriding all other constraints. Used to temporarily disable a Link without deleting it.
_Avoid_: IsLocked, disabled, deactivated

### Organization

**Notes**:
A user-written description of a Link, provided at creation time. Free-form text for the user's own reference. Distinct from the scraped description in Link Metadata.
_Avoid_: Description, comment

**Group**:
A folder-like container that holds Links. Each Link belongs to at most one Group. Groups have globally unique names (single-user app).
_Avoid_: Folder, collection

### Metadata

**Link Metadata**:
Open Graph data scraped from the Link's target URL. Contains a scraped title, scraped description, image URL, and site name. Scraped automatically and lazily — when a social media crawler first requests the Link — so shared Links unfurl with a rich preview. The scraped title is distinct from the user-written Title on the Link.
_Avoid_: OG data, link preview, scraped data
